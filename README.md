Grand Hotel – Reservation Management System

This is a multi-page web application that allows customers to browse rooms, check availability, and book stays, along with an admin interface to manage reservations.

Features:
Real-time room availability tracking
Double-booking prevention using date overlap logic
Admin dashboard with search, edit, cancel, and check-out options
Automated billing calculation based on stay duration
Data persistence using browser LocalStorage
Tech Stack:
HTML
CSS
JavaScript
Note:

This project uses a frontend-based storage approach (LocalStorage) and can be extended with a backend for scalability and security.
